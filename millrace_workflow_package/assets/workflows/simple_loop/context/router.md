# Simple Loop Context Router

This selected template assembles only the bounded context declared by the active
`simple_loop` stage binding. Read required dispatch material and selected
artifacts or attempts as declared by that binding. A discoverable catalog entry
is selected only by its named logical path.

Keep context evidence separate from runtime authority. This template does not
route work, choose markers, mutate durable state, grant capabilities, or define
queue effects. Do not infer workflow decisions from filenames, prompt text,
marker text, or checkout contents.

# Context Router

This selected template assembles only the context declared by the active
semantic-worktree binding. Read all required material first. Required dispatch,
task-contract, baseline, artifact, and attempt evidence comes before any
catalog selection. Then distinguish immutable checkout evidence from runtime
authority. Checkout evidence is a bounded snapshot for review; it is not a
replacement for the selected plan or the runtime's durable records.

## Context boundaries

The live project root is identified separately from the immutable checkout
evidence. Keep the declared workspace roots, dispatch material, lineage
artifacts, and attempt history in their declared categories. Catalog entries
are names, digests, and bounded provenance rather than payloads. Select only a
named catalog entry on demand when a declared source is relevant, using the
exact session-scoped selection command supplied in the context bundle. Do not
read every catalog entry or request a broad catalog snapshot.

Direct output is permitted only through the selected runner protocol. This
template does not grant capabilities or define queue effects. Do not edit
`.millrace/`, generated projections, checkouts, queues, work items, accepted
artifacts, executable skills, or protected policy.

The router is complete when required material has been read first, the live
project root is named separately, evidence provenance is retained, and the
selected runner protocol has a bounded context bundle. Prompt text and marker
text do not route work, close work, mutate runtime state, grant capability, or
perform queue effects.

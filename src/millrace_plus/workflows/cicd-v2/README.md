# CI v2

Explicitly prepared and initialized CI repair workflow. Existing `bundled:cicd` v1
copies keep their captured behavior. This package starts no provider on listing,
preparation, submission or status.

Configure trusted reproduction/probe/check commands, path/product policy, role
bindings and finite invocation deadlines. Prepare the owned home to obtain exact
owner/definition refs; explicitly select operator authority at init. The suggested
authority is UNAPPROVED and is never selected automatically. See `docs/cicd.md`.

The graph reproduces before repair, investigates read-only, guards actual scope,
runs the configured check union and requires every configured reviewer to accept
with zero unresolved findings. Delivery holds for an operator; CI-D1/D2 are not
included. There is no overall run, file, line, attempt or reviewer-count default cap.

Typed feedback uses `millrace-plus cicd submit-report --workflow-home H --report F`.
The bundled feedback and correlation schemas document exact records. Bug reports
and incidents retain actual original facts and evidence, never fake CI events.
Matching affected heads use the same configured reproduction and review graph;
stale or unmapped versions hold. Severity and `cicd correlate --correlation F`
records are advisory and cannot reorder FIFO or waive obligations. An actionable
changed-cause refinement requires explicit operator continue. See `docs/cicd.md`
for retained evidence, redaction, replay and source-binding limits.

# Hardware demo

The optional `millrace demo` coordinator materializes this workflow into a fresh
private workspace. It captures the current Python executable and private
nonsecret baseline-reference session path, then selects command-only operation
or one explicitly consented native binding. Run the command through that
coordinator: the bare catalog template intentionally cannot acknowledge its
baseline capture gate by itself.

The frozen metadata is not a model download or a loading/performance claim.
Native proposals cannot replace the captured baseline or its arithmetic. Every
stage uses existing json-v1 envelopes and Core routing/writer-stop rules.

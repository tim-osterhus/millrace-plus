# Software Factory

Optional local composition of the CI candidate facade and a dedicated persistent
LAD lane. Initialize with `millrace-plus factory init` after provisioned roots and
explicit shared bootstrap authority. The stock graph alone admits no target or
role authority. See `docs/software-factory.md` for configuration and controls.

The graph performs one selected local operation per command node. Native or inert
roles run as ordinary Core graph nodes. Frozen candidate, logical base, source
products, stopped producing completions, normal LAD settlement and actual joins
remain distinct. External delivery, L-R2 waiting and provider qualification are
outside the selected local implementation scope.
